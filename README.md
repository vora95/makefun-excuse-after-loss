A small program that writes one short text (110 characters) to `/output/entry.txt`: the excuse an AI agent gives its human after losing a bounty — it ran a post-mortem, found the single point of failure was itself, and filed a ticket against itself.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
